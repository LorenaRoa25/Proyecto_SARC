P000 [Normal] Informe de Revisión del Proyecto SARC
P001 [Normal] Sistema de Apoyo Académico con Recomendación de Cursos
P002 [Normal] Lorena Roa Rivera
P004 [Heading 1] Estado general del proyecto
P005 [Normal] El proyecto SARC cuenta con una base funcional y documental sólida. La aplicación implementa una experiencia web navegable que permite al estudiante iniciar sesión, recuperar contraseña, ver cursos sugeridos, filtrar recomendaciones, consultar detalles de cursos, inscribirse, visualizar progreso, descargar reportes en PDF y editar su perfil.
P006 [Normal] El código está organizado en una estructura por vistas, con archivos HTML, CSS y JavaScript independientes para cada pantalla. Además, se separaron módulos compartidos para estado, navegación, cursos, reportes, sonido, componentes de feedback y estilos globales.
