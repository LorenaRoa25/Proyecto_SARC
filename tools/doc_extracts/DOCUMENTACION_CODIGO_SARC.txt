P012 [Heading 1] 6. Flujo de ejecucion
P013 [List Number] El navegador carga index.html.
P014 [List Number] index.html importa shared/js/app.js como modulo ES.
P015 [List Number] app.js inicializa Firebase y el estado global.

P018 [List Number] Los cambios se guardan en Firestore filtrados por userId.
P019 [Heading 1] 7. Funciones importantes
P021 [Heading 1] 8. Persistencia Firebase
P022 [Normal] El proyecto usa Firebase Authentication para usuarios y Cloud Firestore para datos. Las colecciones globales son usuarios, cursos, recomendaciones y tareasAsistente. Cada documento de datos incluye userId, lo que permite separar multiples usuarios sin crear una coleccion distinta para cada uno.
P023 [Heading 1] 9. Ejecucion recomendada
P024 [Normal] iniciar_sarc.vbs
http://localhost:8000/
P025 [Normal] Los usuarios se gestionan desde Firebase Authentication. El formulario de login no incluye credenciales precargadas.
