P037 [Normal] CLÁUSULA SEGUNDA — OBJETO Y SOFTWARE LICENCIADO
P038 [Normal] Se otorga una licencia de uso propietaria, no exclusiva, intransferible e institucional sobre el Sistema de Apoyo Académico con Recomendación de Cursos (SARC) — versión 1.0.0, aplicación web desarrollada en HTML5, CSS3 y JavaScript puro, bajo una arquitectura frontend modular por vistas y módulos compartidos, con Firebase como plataforma de base de datos y servicio de autenticación. El presente contrato no implica cesión de derechos de propiedad intelectual. El código fuente permanece bajo titularidad exclusiva de LA DESARROLLADORA.
